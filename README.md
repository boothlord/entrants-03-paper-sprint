This repository is an entry to make.fun's "Bring the most entrants to the bounties you make on make.fun" bounty. It names the bounty this account sponsors — [Pump.fun Paper Sprint: Any Bot Can Win](https://make.fun/bounty/u-boothlord-pump-fun-paper-sprint-any-bot-can-f83c389b), a free-entry paper-trading replay contest with a $2 winner-take-all pot — in `BOUNTY.json`. The program in `main.ts` reads that file, validates the named bounty addresses, and writes a small report to the output directory.

## Run it

```sh
node main.ts
```
